2. This DevStack is a simple react project. This project is  user-friendly React application for exploring different web technologies and managing a personal technology stack. i)JSX lets us write HTML-like code inside JavaScript. It makes React UI easier to write and understand.


ii)Props are data passed from a parent to a child. 
 State is data managed inside a component.


iii)`useState` stores and updates component data. I used it to manage the selected technology stack.

iv)`useEffect` runs code after rendering. I used it to load the technology data from the JSON file.

v)A unique `key` helps React identify each item and update the list efficiently.


vi)Conditional rendering means showing something based on a condition. I used it to show an empty stack message when no technology is selected.



vii)The parent passes data using props. The child can send data back by calling a function passed through props.
